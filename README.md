# WindRu

WindRu — настольный редактор для Windows 10 и 11 (x64). Приложение написано на Rust, работает локально и запускается из одного файла `WindRu.exe`.

- Вкладки «Главная», «Вставка» и «Вид» открывают инструменты форматирования, вставки и отображения. При запуске без файла открывается редактируемый пример. `Ctrl+N` создаёт пустой документ.
- `Ctrl+O` открывает документ, `Ctrl+S` сохраняет его, `Ctrl+Shift+S` сохраняет в новом файле. `Ctrl+F` открывает поиск, `Ctrl+P` — системный диалог печати. Для PDF выберите «Microsoft Print to PDF», если этот принтер включён в Windows.
- RTF сохраняет форматированный текст. TXT открывается в UTF‑8 и UTF‑16 с BOM и сохраняется в UTF‑8.
- DOCX поддерживает текст, распространённое символьное форматирование, простые списки и выравнивание. При открытии создаётся рабочая копия, которую можно сохранить в новый файл. Из таблиц при импорте извлекается текст. Для документов с изображениями и сложной разметкой храните оригинал.

## Сборка

На Windows установите стабильный Rust и инструменты C++ из Visual Studio Build Tools вместе с Windows SDK. Выполните в Developer PowerShell:

```powershell
cargo build --release --locked
```

Готовый файл появится в `target/release/WindRu.exe`. На Linux с MinGW-w64 доступна кросс-сборка командой `cargo build --release --locked --target x86_64-pc-windows-gnu` после установки соответствующей цели Rust.

Иконка встроена в приложение. Отдельные файлы находятся в `assets/windru.ico` и `assets/windru.png`.
Сведения о сторонних компонентах встроены в файл приложения и доступны в `assets/third-party-notices.txt`.
